## Description

Every team asks the same questions in chat, every week. Can we refund this? Is this okay to expense? The answers live in one manager's head.

Precedent fixes that. Answer once in Slack, and your AI agents remember it as a rule. Next time, the agent already knows the answer and you just say yes. If a case is different, it asks you instead of guessing.

### How it works

1. You answer once, in Slack, in plain words.
2. It becomes a rule, tested on past decisions before it's saved.
3. Next time, the agent brings the answer and you confirm in one line.

### Built with Switch

Precedent runs in a Switch room connected to Slack, with three AI agents: Clerk, Judge and Auditor.

- The AI only reads and writes the words. Plain code makes the decision.
- Every approval is checked against Switch's own record of who sent it, so an agent's word isn't enough.
- Every step is saved as a git commit.
